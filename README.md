# US & LV India (OPC) Pvt Ltd — Official Website

This repository contains the source code for the official website of **US & LV India (OPC) Pvt Ltd** (*The Growth Transformers*). The site provides comprehensive information regarding the firm's multi-disciplinary advisory services in Educational Guidance, Career Counselling, and Financial Wealth Advisory.

---

## 🌟 Key Features

* **Hero Section & Lead Capture**: Instant appointment booking form for prospective clients.
* **Core Pillars**: Highlights the company's three main vectors: *Transforming Minds*, *Transforming Careers*, and *Transforming Wealth*.
* **Leadership Profiles**: Detailed profiles for company directors:
  * **Ms. Latha Deora** (Educational Advisory & Holistic Mindset)
  * **Mr. Umesh Kumar Deora** (Career Architecture & Financial Strategy)
  * **Mr. Shripal Deora** (Technology Innovation & Strategic Operations)
* **Interactive Services Hub**: Clean categorization of Educational, Career, and Financial services.
* **Fully Responsive**: Optimized for mobile phones, tablets, and desktop computers.
